# Agentic AI in Six Weeks

A free, self-paced, no-code course on building AI agents. It follows the same six-week syllabus as *Mastering Agentic AI* (The Gen Academy), using only free, public videos, courses and readings.

Open `index.html` in any browser to use it. Progress (ticked sources, build steps and quiz answers) saves in your browser.

## What's inside

| Week | Topic | Build |
|---|---|---|
| 0 | Start here | Setup checklist, costs, weekly rhythm |
| 1 | How LLMs actually work | Your assistant, version 1 |
| 2 | Ground it in your documents (RAG, context, memory) | Grounded Q&A over your own documents |
| 3 | Make it an agent (tools, MCP, patterns) | A research and briefing agent in n8n |
| 4 | Test it with evals | An eval kit for your agent |
| 5 | Customize the model (fine-tuning, local models) | Local model lab and a fine-tuning dataset |
| 6 | Secure it and ship (prompt injection, guardrails) | Red-team your agent, then ship |
| ★ | Capstone | One agent you can show, with evals and a README |

Each week has a plain-English explanation, 4–5 hours of curated free sources, a hands-on build of about 5 hours, a 4-question quiz, and prompts to paste into Claude for tutoring. Plan on 10–12 hours a week.

## Main sources

- Andrej Karpathy: *Deep Dive into LLMs like ChatGPT* and *How I use LLMs* (YouTube)
- Andrew Ng: *Generative AI for Everyone* (Coursera, free audit) and *Agentic AI* (DeepLearning.AI, free audit)
- Anthropic Academy courses and *Building effective agents*
- IBM Technology explainers on agents, RAG, MCP and fine-tuning
- Hamel Husain on evals and LLM-as-judge
- Simon Willison on prompt injection and the lethal trifecta; OWASP Top 10 for LLM Applications
- Free Live Labs and Lightning Lessons from The Gen Academy
- Tools: Claude Projects, NotebookLM, n8n, LM Studio, Lakera's AI-hacking game

Links were checked on October 8, 2026.

## Costs

Everything is free except, optionally: n8n Cloud after its 14-day trial, a few dollars of AI model credit if you don't use a free tier, and a small optional fine-tuning run in Week 5.
